## Используемые технологии и СУБД
- **Язык и платформа:** Java (JDK 25 LTS)
- **Система сборки:** Apache Maven
- **СУБД:** H2 Database (`jdbc:h2:mem:testdb`)

## Порядок подготовки базы данных
База данных H2 запускается автоматически в оперативной памяти при старте программы:
1. Создаётся схема `study`.
2. Выполняется скрипт `music-create.sql`.
3. Создаются таблицы `visitors`, `books`, `visitor_books` и импортируются уникальные записи из `books.json`.

## Команда сборки и запуска программы

1. Сборка и запуск программы:
   ```bash
   mvn clean compile exec:java
   ```
